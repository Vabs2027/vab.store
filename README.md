# VAB Store

A full-stack clothing store web application built with React and Django REST Framework.

## About the Project

VAB Store is a personal full-stack web development project focused on building an online clothing store. It combines a React frontend with a Python and Django REST Framework backend, communicating through a REST API.

The project is an opportunity to develop practical skills in frontend development, backend programming, API integration, database management, and version control.

## Project Structure

- `store/` — Django backend, REST API, database configuration, and migrations
- `store-frontend/` — React frontend
- `README.md` — project overview and technologies
- `.gitignore` — specifies files and folders excluded from Git tracking

## Getting Started

The backend and frontend have separate setup instructions.

- **Backend:** Django setup instructions and dependencies are located in the `store/` directory. The backend dependencies are listed in `store/requirements.txt`.
- **Frontend:** React installation, development server, and production build instructions are available in [`store-frontend/README.md`](store-frontend/README.md).
